# AMS Console presentation

- `ams-console-deck.html`: the demo deck. Open it in a browser. Click or press the right arrow to move on, the left arrow to go back, `F` for full screen. Slide 5 walks one ticket through the five agents click by click.
- `ams-console-deck-first-version.html`: the earlier design, in the console's own colours.
- `slides-source/`: the same ten slides as source files for the editable slide deck (`deck.json`, `deck.css`, one file per slide).

The fonts load from Google Fonts; offline the deck falls back to system fonts.

Before presenting, check slide 7: the Triage figure is a placeholder, and the scores shown come from the status table in the root `README.md`.
